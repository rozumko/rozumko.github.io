## 3. Перекіс типів у 2–4 класах

Питання з блоком псевдокоду (`code != null`): 1 клас — 0/39, 2 клас — 27/27,
3 клас — 27/27, 4 клас — 26/27. Тобто всі місії 2–4 класів — «читання
псевдокоду», а «Обчислювальне мислення» і «Основи ШІ» як напрями не мають
власного контенту. Це блокує:

- іменовані місії (кілька «різних» місій з одного пулу = фейкова різноманітність);
- прев'ю на вітрині для старших класів (зараз бере лише grade-1);
- змістовний вибір напряму в Home Mode (fallback за difficulty підміняє track).

Рекомендований мінімум на клас: ~15 питань на напрям без коду (мислення:
закономірності, послідовності, уважність; ШІ: дані/підказки/етика простими
словами).

## 4. Розмітка `track`

Колонка `track` вже підтримується API (`GET /api/questions?track=…`), але старі
питання не розмічені — `home-demo.ts` живе на fallback за difficulty. План:

1. Розмітити наявні питання в БД: `code != null` → `informatics`;
   алгоритми-рухи-закономірності без коду → `computational-thinking`;
   питання про дані/ШІ → `ai-basics` (зараз таких майже немає — див. п. 3).
2. Перегенерувати статичний бандл (`npm run export:questions`).
3. Після розмітки прибрати fallback у `home-demo.ts` (коментар «Тимчасовий
   fallback…» у `loadDemoQuestions`).
