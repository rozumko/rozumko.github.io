# Формат завдань — РОЗУМКО

_Останнє оновлення: 2026-04-28_

## Принцип

Завдання зберігаються в JS-файлах у `data/questions/{subject}/`.
Два окремі банки — тренувальний і олімпіадний — **не перетинаються**.

| Файл | Призначення | Режими |
|---|---|---|
| `grade{N}.js` | Тренування і демо | `practice`, `demo` |
| `grade{N}-olympiad.js` | Олімпіада | `olympiad` |

Кожен файл експортує масив `questions`. Кожен елемент — об'єкт із полем `type`.
Формат зворотно сумісний: `type: 'choice'` можна не писати (default).

---

## Типи завдань

### 1. `choice` — одиночний вибір (поточний тип)

```js
{
  type: 'choice',           // можна не писати — default
  difficulty: 'easy',
  q: 'Яке з цих пристроїв — пристрій виведення?',
  a: ['Клавіатура', 'Монітор', 'Мишка', 'Сканер'],
  correct: 1,               // індекс правильної відповіді
  explanation: '...'
}
```

---

### 2. `sort` — розставити у правильному порядку

Учень бачить перемішані елементи і перетягує їх у правильну послідовність.

```js
{
  type: 'sort',
  difficulty: 'medium',
  q: 'Розстав кроки збереження файлу у правильному порядку:',
  items: [
    'Натисни Ctrl+S',
    'Відкрий програму',
    'Набери текст',
    'Введи назву файлу'
  ],
  correctOrder: [1, 2, 0, 3],  // індекси items у правильній послідовності
  explanation: '...'
}
```

`correctOrder[0] = 1` означає: перший правильний крок — `items[1]` ("Відкрий програму").

---

### 3. `sequence` — продовж послідовність

Учень бачить початок і вписує або вибирає наступний елемент.

```js
{
  type: 'sequence',
  difficulty: 'easy',
  q: 'Що стоїть наступним?',
  given: ['🟥', '🟦', '🟥', '🟦'],
  answer: '🟥',             // правильна відповідь (рядок)
  choices: ['🟥', '🟩', '🟦', '🟨'],  // варіанти (якщо є — вибір; якщо нема — введення)
  explanation: '...'
}
```

---

### 4. `match` — з'єднай пари

Учень з'єднує елементи лівого стовпця з правим.

```js
{
  type: 'match',
  difficulty: 'medium',
  q: 'З\'єднай пристрій із його призначенням:',
  left:  ['Клавіатура', 'Принтер', 'Монітор'],
  right: ['Виводить зображення', 'Вводить текст', 'Друкує на папері'],
  pairs: [1, 2, 0],   // pairs[i] = індекс у right для left[i]
                       // Клавіатура → right[1], Принтер → right[2], Монітор → right[0]
  explanation: '...'
}
```

---

### 5. `algorithm` — склади алгоритм

Семантично схожий на `sort`, але контекст — кроки програми або задачі.
Окремий тип дозволяє рендерити його з виглядом блок-схеми або нумерованого списку.

```js
{
  type: 'algorithm',
  difficulty: 'hard',
  q: 'Склади правильний алгоритм для робота, щоб він намалював квадрат:',
  items: [
    'Повернись праворуч',
    'Іди вперед 3 кроки',
    'Повторити 4 рази:',
    'Зупинись'
  ],
  correctOrder: [2, 1, 0, 3],
  explanation: '...'
}
```

---

## Поля спільні для всіх типів

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `type` | string | ні (default: `'choice'`) | Тип завдання |
| `difficulty` | `'easy'`\|`'medium'`\|`'hard'` | так | Рівень складності |
| `q` | string | так | Текст запитання |
| `explanation` | string | рекомендовано | Пояснення після відповіді |

---

## Оцінювання

| Тип | Логіка |
|---|---|
| `choice` | 1 бал якщо `answer === correct` |
| `sequence` | 1 бал якщо відповідь точно збігається |
| `sort` / `algorithm` | 1 бал за повністю правильний порядок; 0 за будь-яку помилку |
| `match` | 1 бал за всі правильні пари; можна розширити до часткового балу |

---

## Порядок реалізації рендерерів

1. `choice` — вже є ✅
2. `sort` — наступний (drag-and-drop або кнопки «вгору/вниз» для мобільних)
3. `sequence` — простий (вибір або введення)
4. `match` — середня складність (лінії або select)
5. `algorithm` — після `sort` (той самий рендерер, інший стиль)

## Приклад реального файлу (змішані типи)

```js
// data/questions/informatics/grade2.js
export const questions = [
  {
    type: 'choice',
    difficulty: 'easy',
    q: 'Яку кнопку натиснути щоб зберегти файл?',
    a: ['Ctrl+C', 'Ctrl+V', 'Ctrl+S', 'Ctrl+Z'],
    correct: 2,
    explanation: 'Ctrl+S — Save (зберегти).'
  },
  {
    type: 'sort',
    difficulty: 'medium',
    q: 'Розстав кроки у правильному порядку:',
    items: ['Зберегти файл', 'Відкрити програму', 'Набрати текст'],
    correctOrder: [1, 2, 0],
    explanation: 'Спочатку відкриваємо програму, потім набираємо текст, потім зберігаємо.'
  },
  {
    type: 'sequence',
    difficulty: 'easy',
    q: 'Що стоїть далі: 2, 4, 6, 8, ...?',
    given: ['2', '4', '6', '8'],
    answer: '10',
    choices: ['9', '10', '12', '16'],
    explanation: 'Кожне наступне число більше на 2.'
  }
];
```
