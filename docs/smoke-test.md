# MVP Smoke Test — Розумко

Ручний чеклист для перевірки повного сценарію перед пілотом.

_Оновлено: 2026-05-15_

---

## Адмін

- [ ] Логін в адмін-панель
- [ ] Створити подію олімпіади (назва, дати, статус `draft`)
- [ ] Додати питання для кожного класу (1–4) до події
- [ ] Перевірити що питань вистачає (≥ кількості у квізі)
- [ ] Змінити статус події на `active`

## Вчитель

- [ ] Логін у кабінет вчителя
- [ ] Створити клас (наприклад, "3-А тест")
- [ ] Додати 2–3 учнів (мітки: "Учень 1", "Учень 2")
- [ ] Зареєструвати клас на активну подію
- [ ] Згенерувати коди — перевірити що з'явилися в таблиці
- [ ] Скопіювати один код

## Учень (через `olympiad-enter.html`)

- [ ] Відкрити `olympiad-enter.html`
- [ ] Ввести неправильний код → побачити помилку (код не споживається)
- [ ] Ввести правильний код → з'явився Крок 2 з назвою події та правилами
- [ ] Кнопка "Почати" заблокована до галочки
- [ ] Поставити галочку → кнопка активується
- [ ] Натиснути "Почати" → редирект на `student.html`
- [ ] Квіз стартував автоматично в олімпіадному режимі
- [ ] Відповісти на всі питання → натиснути "Завершити"
- [ ] Побачити результат

## Вчитель — результати

- [ ] Зайти у вкладку Results
- [ ] Побачити спробу "Учня 1" з балом
- [ ] Відкрити сертифікат → ввести ім'я → роздрукувати / зберегти PDF

## Перевірка безпеки

- [ ] DevTools → Network → у відповідях API немає поля `correct`
- [ ] localStorage / sessionStorage → `pendingOlympiad` очищено після старту квізу
- [ ] POST на `/api/attempt/:id/answer` без `X-Attempt-Token` → відповідь `403`
