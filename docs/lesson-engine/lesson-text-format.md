# Текстовий формат уроку

Керований урок можна написати звичайним текстом і вставити в адмінці
(«Уроки» → «Створити урок»). Платформа сама розкладе текст на кроки,
слайди й завдання. У редакторі кнопка «Урок як текст» робить зворотне: показує
чернетку в цьому ж форматі, щоб її можна було змінити деінде (або попросити
ШІ) і створити з неї новий урок.

У вікні «Створити урок» є каркаси уроків (25 хв для 1–2 класу, 40 хв для 3–4,
практична робота, урок-обговорення) і промпт для ChatGPT, Claude чи Gemini,
який переписує готовий урок з HTML, Word або конспекту в цей формат.

Код: `features/admin/curriculum-text.ts` (`parseLessonText`, `lessonToText`),
`features/admin/curriculum-text-templates.ts` (каркаси, приклад, промпт),
тести `features/admin/curriculum-text.test.mjs` (кожен розібраний урок
проходить справжній серверний валідатор; текст → урок → текст → урок дає той
самий урок).

## Приклад

```
# Цифрове і нецифрове навколо нас
Клас: 1
Тривалість: 25 хв
Цілі:
- Розрізняти цифрові та нецифрові справи.
Урок виконується в парах. Потрібні папір і олівці.

## Одна справа — два способи
Ти хочеш намалювати кота. Це можна зробити двома способами.
[слайд] ![Діти працюють із планшетом](https://commons.wikimedia.org/…)
[слайд] **Цифровий спосіб** — з пристроєм. **Нецифровий** — власноруч.
Підказка: Де помилку прибрати легше — гумкою чи кнопкою?
Для вчителя: Фото на телефон — теж цифрова справа.

## Спробуй: дві коробки
? Розклади справи по коробках.
[Digital] грати в гру на комп'ютері
[Non-digital] читати паперову книжку

## ☕ Перерва
Встаньте й покажіть руками, як ви малюєте на папері.

## Перевір себе
? Яка справа є нецифровою?
- Надіслати бабусі фото з телефона
+ Пограти в класики на подвір'ї
= Класики: тут не потрібен жоден пристрій.

? (перевірка) Правда чи ні?
Правда: Планшет — цифровий пристрій.
Неправда: Олівець — цифровий пристрій.
```

## Правила

### Урок

| Рядок | Що означає |
|---|---|
| перший непорожній рядок (з `#` або без) | назва уроку |
| `Клас: 2` | клас (у межах предмета, для інформатики 1–4); без рядка — найменший клас предмета |
| `Тривалість: 25 хв` (або `Час:`) | тривалість уроку; без рядка — 40 хв |
| `Цілі:` і рядки `- …` під ним | цілі уроку |
| інший текст до першого кроку | опис уроку лише для вчителя (блок «Про урок») |

### Кроки

- `## Назва` починає крок. Кожен крок стає блоком «Текст і медіа» і кроком
  у консолі вчителя.
- `## Перерва` (можна з ☕) — перерва; текст під ним — інструкція.
- Кожен рядок — окремий абзац. Порожні рядки лише розділяють.
- Довгий крок (понад 20 елементів) ділиться на кілька блоків з тією ж назвою.

### Вміст кроку

| Рядок | Результат |
|---|---|
| звичайний текст | абзац; `**жирний**` і `` `код` `` працюють, HTML — ні |
| `### Підзаголовок` | підзаголовок |
| `- пункт` (або `*`, `•`) | список |
| `1. пункт` | нумерований список |
| `\| A \| B \|` у кількох рядках | таблиця; перший рядок — заголовки; таблиця з одним стовпцем стає списком |
| `![опис](https://…)` | зображення (адреса https або шлях на сайті `/…`) |
| `[текст](https://…)` або адреса окремим рядком | посилання; посилання на YouTube стає відео |
| `Підказка: …`, `Допомога: …`, `Більше: …` | абзац із позначкою 💡 / 🆘 / 🚀 |

Позначки на початку рядка:

- `Для вчителя:` — рядок бачить лише вчитель (план уроку). Він не
  потрапляє ні на дошку, ні на пристрої учнів.
- `[слайд]` — рядок потрапляє на слайд. Якщо в кроці немає жодного
  `[слайд]`, на слайді буде перше зображення кроку, а без зображення — перше
  речення. Так на дошці лишається лише головне.

Учні на пристроях бачать увесь крок, крім рядків «Для вчителя».

### Завдання

Рядок `?` починає завдання. Варіанти йдуть одразу під ним, без порожніх
рядків. Завдання закінчується на порожньому або звичайному рядку.

| Вид | Рядки під `?` |
|---|---|
| Вибір однієї відповіді (2–6 варіантів) | `+ правильний`, `- неправильний`; `= пояснення` після відповіді |
| Правда / неправда (1–10 тверджень) | `Правда: …`, `Неправда: …` |
| Розподіл по групах (2–4 групи, 2–20 предметів) | `[Група] предмет` |

- Правильну відповідь позначає автор. Завдання без `+` або з двома `+` — це
  помилка з номером рядка. Платформа відповідь не вгадує.
- Пояснення `=` і ключ зберігаються лише на сервері. Учні бачать їх тільки
  після відповіді.
- `? (перевірка) …` — завдання-перевірка (сигнал учителю під час уроку).
  `? (оцінювання) …` — завдання-доказ для звіту; його треба пов’язати з
  результатом навчання в редакторі, інакше урок не збережеться. Без позначки
  завдання тренувальне.

## Чого немає в тексті

Результати навчання, словник, хвилини кроків, нотатки до слайдів, зовнішні
тренажери та ігри платформи налаштовуються в редакторі. «Урок як текст»
називає блоки, які не ввійшли в текст.
