# Формат кодів доступу для учнів

## Поточний стан (генерація)

`generateCode()` у `backend/src/routes/teacher.ts` генерує 6-символьний рядок
із латинського алфавіту + цифр: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.

Приклад: `KJ3T8M`

## Цільовий формат (TODO)

Для учнів 1–4 класів — максимально простий і читабельний код:

```
КІТ247   ← СЛОВО (до 5 укр. літер) + 3 цифри
247КІТ   ← або 3 цифри + СЛОВО
```

### Правила

- Слово: 2–5 букв українського алфавіту (А–Я, Ґ, Є, І, Ї)
- Цифри: рівно 3 (`000`–`999`)
- Порядок: `СЛОВО+ЦИФРИ` або `ЦИФРИ+СЛОВО` — обидва дійсні
- Регістр: не важливий (`кіт247` = `КІТ247`), нормалізується на сервері
- Без пробілів, тире, дефісів

## План змін

### 1. `backend/src/routes/teacher.ts` — нова функція генерації

```ts
const WORDS = ['КІТ','ПЕС','ЛИС','РАК','ВУЖ','ЖУК','БИК','ЛЕВ','КИТ',
               'ВОВК','ОРЕЛ','КОЗА','КІНЬ','ГУСЬ','КРОТ','ТИГР','РИСЬ']

function generateCode(): string {
  const word = WORDS[Math.floor(Math.random() * WORDS.length)]
  const digits = String(Math.floor(Math.random() * 1000)).padStart(3, '0')
  return `${word}${digits}`   // наприклад: КІТ042
}
```

### 2. `backend/src/routes/student.ts` — валідація формату

Перед пошуком у БД — перевірити формат і нормалізувати:

```ts
const raw = req.body.code.trim().toUpperCase()
const CODE_RE = /^([А-ЯҐЄІЇ]{2,5}\d{3}|\d{3}[А-ЯҐЄІЇ]{2,5})$/u

if (!CODE_RE.test(raw)) {
  return reply.code(400).send({ error: 'Невірний формат коду. Приклад: КІТ247' })
}
// далі шукати raw у БД
```

> Поточний код вже робить `.trim().toUpperCase()` перед пошуком — лишається лише
> додати regex-перевірку.

### 3. Fastify schema — оновити `maxLength`

```ts
code: { type: 'string', minLength: 4, maxLength: 10 }
```

(замість поточного `maxLength: 20`)

### 4. Фронтенд — `student.html` / `student.js`

## Міграція існуючих кодів

Старі коди (латиниця, 6 символів) у БД після впровадження нового формату
залишаться дійсними до вичерпання або закінчення терміну дії —
нова regex-перевірка їх відхилить на вході, але вони у БД нікуди не дінуться.

**Рекомендація:** після деплою нової генерації вчителі створюють нові коди,
старі не видаляти вручну — вони самі вичерпаються.
